# SmartSaver Agent Guide

SmartSaver is a personal finance application built with Next.js 16, TypeScript, Drizzle ORM, Tailwind CSS, shadcn/ui, and Playwright.

## Required Reading

Before changing the repository, read the guides relevant to the task:

| Guide | Read when |
| --- | --- |
| [Development commands](docs/agents/development-commands.md) | Running, building, linting, testing, or changing the database |
| [Code conventions](docs/agents/code-conventions.md) | Changing TypeScript, JavaScript, or component code |
| [Project architecture](docs/agents/project-architecture.md) | Adding, moving, or reorganizing files and features |
| [Application patterns](docs/agents/application-patterns.md) | Changing UI, Server Actions, error handling, or database access |
| [Testing guide](docs/agents/testing-guide.md) | Changing behavior or writing Playwright tests |

Read every applicable guide, not only the first match. Treat repository configuration and executable scripts as authoritative when they conflict with documentation, and update the affected guide in the same change.
